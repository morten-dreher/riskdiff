# Distribution function of exact risk difference

Distribution function of exact risk difference

## Usage

``` r
priskdiff(piTreatment, piControl, nTreatment, nControl)
```

## Arguments

- piTreatment:

  Event rate in treatment group.

- piControl:

  Event rate in control group.

- nTreatment:

  Number of subjects in treatment group.

- nControl:

  Number of subjects in control group.

## Value

Aggregated data of risk differences and cumulative probabilities.
