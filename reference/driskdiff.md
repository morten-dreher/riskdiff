# Density of exact risk difference

Density of exact risk difference

## Usage

``` r
driskdiff(piTreatment, piControl, nTreatment, nControl)
```

## Arguments

- piTreatment:

  Event rate in treatment group.

- piControl:

  Event rate in control group.

- nTreatment:

  Number of subjects in treatment group.

- nControl:

  Number of subjects in control group.

## Value

Aggregated data of risk differences and probabilities.
